# V9 — 잔량 감소 + 순정식 소진 정지 + 리필 초기화 후보

[EFU 다운로드](https://media.githubusercontent.com/media/ZanghyunCho/R5690/claude/friendly-ritchie-8ou26m/firmware/custom/virtual-ink-refill-v9/FWE642TL_GR_VIRTUAL_CSIC_MB_T3400_CLUT_MATTE_SML_REFILL_CANDIDATE_v9.EFU)

SHA256: `82bf94481246962096d27f141196c3a43b5377a2d673e127c73f43b294228df4`

부모는 **V7**(V6 가상 카트리지 + T3400 Enhanced Matte SML)입니다. **V8의 "사용량 무시" 수정은 들어 있지 않습니다.**

## 사용 방법

1. 잔량은 실제 사용량에 따라 줄어듭니다. 바닥에 닿으면 **순정처럼 인쇄가 멈춥니다.**
2. 잉크를 채운 뒤 **잉크 커버를 열었다 닫으세요.** 프린터가 팩을 다시 확인할 때 **"부족" 또는 "바닥" 상태인 색만** 100%로 돌아갑니다. 정상 색은 그대로입니다.
3. 4색을 한꺼번에 초기화하려면: 수정 Adjustment Program → Maintenance counter → Maintenance Box counter **Initialize** → 프린터 **전원을 껐다 켜기**.

## 동작 원리

- 순정은 새 잉크팩 ID를 인식할 때 `0x47C5BB68(slot, 0)`으로 그 색의 누적 사용량을 0으로 만듭니다. 가상 칩은 ID가 고정이라 이 일이 일어나지 않았습니다.
- V9는 순정 팩 재확인 `0x47C58AB0` 직전에 작은 도우미를 실행합니다.
  - 상태 배열 `0x47D5EE18`에서 부족(4)·바닥(5/6)인 색 → 순정 새 팩 초기화 함수 호출.
  - 유지보수통 카운터 속성 `0x75B`가 0이면 → 4색 모두 초기화하고 `0x75B`를 1로 기록(한 번만 동작).
  - 속성 관리자가 준비되지 않았으면 아무것도 하지 않음.
- 부팅 직후에는 상태 배열이 0이므로 색별 초기화가 일어나지 않습니다.
- V6의 잔량 100% 고정 훅 2개를 순정으로 되돌렸습니다. 잔량·부족·소진 판정은 순정 그대로입니다.
- 도우미(200바이트)는 V6가 외부 참조 없음을 검증한 은퇴 칩 인증 코드 영역 `0x47C8D8DC`에 있습니다. 화면 버퍼와 겹치지 않습니다.

## 오프라인 검증 (원본 ARM 실행)

- V9 전용(`tools/validate_virtual_ink_refill.py`, 결과 `docs/virtual-ink-refill-v9.json`), SKU 6종 × 사용량 2종:
  - 부팅형 스캔: 초기화 없음.
  - 부족(4)/바닥(6) 색만 다음 스캔에서 0, 다른 색 유지. 가상 칩 카운터도 0으로 따라옴.
  - 초기화 후 사용량 기록·재등록 정상.
  - `0x75B`=0 → 4색 초기화 후 1로 소비, 다음 스캔에서 반복 없음.
  - 준비 전: 도우미 동작 없음. V6 대조군: 초기화 없음.
  - 순정 화면 지우기 후 도우미 보존. 순정 상태 판정(부족 `0x83`, 소진 6, 정상 100%) 활성.
- V6 전체 통합 검증을 V9로 재실행: 스캔 72회·사용량 기록 144회·재등록 144회 통과.
- 시작 회귀: 이른 설정 함수 64건, 활성화 전 진입점 36건 순정과 동일.
- CROM 재압축, 원본 ARM 헤더/LZ 재생 5구간, 14개 레코드 IPL 체크섬·SHA-1, ZIP 재읽기, 별도 추출기 재해제 확인.

## 한계 / 주의

- **실기 미검증.**
- 커버 닫기가 순정 팩 재확인(`0x47C58AB0`)을 부르는지는 호출 관계로 추정한 것입니다. 커버를 열었다 닫아도 초기화되지 않으면 알려 주세요. 비상용 Adjustment Program 초기화는 그와 무관하게 동작해야 합니다.
- `0x75B`가 Adjustment Program이 쓰는 EEPROM `0x28–0x29`와 같은 값이라는 것도 추정입니다.
- "부족" 상태 색은 리필하지 않고 커버만 여닫아도 초기화됩니다.
- 바닥 정지 후에는 반드시 실제로 잉크를 채운 다음 커버를 여닫으세요.
- 문제가 있으면 업데이트 모드에서 V8·V7·순정으로 복원하세요.
