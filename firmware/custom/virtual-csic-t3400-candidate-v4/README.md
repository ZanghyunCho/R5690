# 가상 잉크 CSIC + 유지보수통 + T3400 CLUT v4 후보본

**오프라인 ARM 실행과 파일 무결성 검증을 통과했습니다. 실제 프린터의 부팅·무칩 인쇄·자동 잉크 공급은 미검증입니다.**

기존 V1의 잔량/오류 캐시 덮어쓰기를 제거하고, 네 잉크 슬롯의 읽기·쓰기·등록을 RAM 기반 가상 칩으로 연결했습니다. 가상 칩 ID는 재생성 시에도 일정하며, 실제 칩의 인증 알고리즘을 재현하는 방식은 아닙니다. 순정의 소비량 계산과 등록 시 읽기/쓰기 검사를 유지합니다.

- 잉크 잔량 보고는 100%로 고정합니다. 소비 카운터는 검증 일관성을 위해 별도로 유지합니다.
- 기존 유지보수통 패치와 T3400 공통 용지 모드 CLUT는 유지합니다.
- 일반 잉크 오류 처리, IES·누수 센서·펌프 분기와 Initial Charge 플래그는 덮어쓰지 않습니다.
- 실제 칩 이력을 지우지 않습니다. 가상 슬롯은 순정의 물리 칩 이력 없음 값을 사용합니다.
- 다른 해상도·하프톤·디더·총 잉크량 이식은 포함하지 않습니다.

검증: 합성 속성/OS 환경에서 순정 전체 스캔 72회, 소비량 기록 144회, 재등록 144회, 별도 초기 RAM 재구성 4회. 오류 API 232개 사례는 기존 유지보수통 전용 코드와 동일합니다. 물리 칩 통신 및 칩 이력 객체 쓰기/포맷 호출은 검증 경로에서 발생하지 않았습니다. 미지원 SKU는 실패를 반환하고, 순정 대조군은 실제 하드웨어 경로에 진입합니다.

기존 T3400 LUT v1에서 GR 컨트롤러 영역과 그 무결성 필드만 변경했습니다. 부트 코드, 라이브러리, IC3·IC5 및 GH 변형 데이터는 부모 EFU와 동일합니다. 14개 레코드 무결성, 5개 CROM의 원본 ARM 복원, 독립 IPL 보정기와 ZIP 재읽기를 확인했습니다. 하드웨어 Huffman 주변장치와 프린터 전체 OS는 에뮬레이션하지 않았습니다.

다운로드 후 `SHA256SUMS`의 해시와 비교할 수 있습니다. 상세 결과는 `manifest.json`에 있습니다. 이 후보본의 실제 장치 성공 여부는 아직 확인되지 않았습니다.
