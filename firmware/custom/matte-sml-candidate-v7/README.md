SHA256: `5040470409309b63d070841cd3606858bf891e6a507c42ded7e589c805207859`

## 바뀐 것

V6에서 **R5691 SML 214 하나만** T3400 Enhanced Matte(L_APMP_MK, 1200×1200, 2비트)의 SML 213으로 바꿨습니다.
SML은 농도별로 작은·중간·큰 도트를 어떻게 나눌지 정하는 하프토닝 데이터입니다.

- 영향 모드: 일반 용지 1200×1200 2비트 — CMM 14(BASE), 414(E-RGB), 574(E-BIZ-COLOR). 다른 품질·용지는 그대로입니다.
- 변경 위치: GR 라이브러리 CROM 한 구간. 리소스 13의 사용하지 않는 압축 꼬리(1,872바이트)에 658바이트를 넣고 214의 포인터만 바꿨습니다. 라이브러리 크기·주소는 그대로입니다.
- 컨트롤러, 주 프로그램, 부팅 코드, 디더(652), CLUT, 가상 CSIC·유지보수통 패치는 V6와 바이트 단위로 같습니다. 새 코드는 없습니다.

## 오프라인 검증

- 라이브러리 리소스 87개 전체를 원본 ARM 해제기로 풀어 비교: 바뀐 리소스는 214뿐이고, 결과는 도너 SML 213과 해시 일치.
- 원본 리소스 조회 `0x480994C0`, 카탈로그 선택 `0x48ABE280`, SML 파서 `0x48ABF630` 통과(합성 입력).
- 순정 허프먼 표 유지 CROM 재압축(무효화된 복사 12개만 literal로 교체), 원본 ARM 헤더/LZ 재생 5개 구간 일치.
- 14개 레코드 IPL 체크섬·SHA-1, ZIP 재읽기, 별도 추출기로 재해제 일치. 변경 범위 외 rcx 바이트 동일.
- 도너 확인: 새로 받은 `FWF649TL_LN22Q1.efu`의 SML 213, 디더 702/662/682가 기존 도너와 해시 동일.
- 별도 `rcx_correct` 교차 검증은 이 환경에 도구가 없어 수행하지 못했습니다.
